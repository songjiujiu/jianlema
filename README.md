# 减了嘛小程序

一个减脂拍照打卡小程序 MVP。

## 当前能力

- 今日拍照打卡。
- 可选记录体重、心情和备注。
- 首页展示今日状态、连续打卡天数、最近 7 天记录。
- 漏打卡弹窗提醒。
- 温和、犀利、地狱三档文案模式。
- 进度日历。
- 历史照片列表。
- 两张照片前后对比。
- 本地体重趋势。
- 本地资料设置和数据清空。

## 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前目录：`d:\ai-agent\jianlema`。
4. `appid` 当前使用 `touristappid`，可先以测试号方式预览；正式开发时替换为真实小程序 AppID。

## 技术说明

- 当前版本使用微信原生小程序。
- 数据暂存在本机 `wx.setStorageSync`。
- 图片通过 `wx.chooseMedia` / `wx.chooseImage` 选择，并优先用 `wx.saveFile` 保存到本地。
- 暂未接入云开发、对象存储和服务端鉴权。
